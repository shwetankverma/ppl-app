HOW TO ADD EXERCISE GIFS
========================
Drop GIF files into this folder using the exact filenames below.
The app shows the GIF automatically; any missing file falls back
to the muscle map. Source them from wherever you have rights to
use (sites like FitnessProgramer let you download for personal use).
Once viewed online, each GIF is cached for offline gym use.
